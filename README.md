# 移动端安全工单处置Android App
## 项目介绍
面向安全运维人员的轻量化工单处置移动端工具，方便外勤人员查看、跟进安全风险工单。
## 技术栈
Android + Java，后端 Python + MySQL
## 功能实现
1. 用户登录，区分不同角色查看对应工单
2. 工单列表展示，按风险等级（高危/中危/低危）筛选
3. 工单详情查看、添加处置备注、状态更新（待分派→处置中→复测→关闭）
4. 到期提醒，跟进逾期安全工单
## 项目说明
本项目由课程任务管理App改造而来，重点练习安全工单闭环业务流程、风险分级的产品逻辑，输出配套原型文档。
## 收获
理解安全事件工单流转流程，学会从使用者角度设计安全运维工具。
